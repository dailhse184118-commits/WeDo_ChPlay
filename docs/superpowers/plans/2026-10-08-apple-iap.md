# Kế hoạch triển khai In-App Purchase (Apple) cho WeDo iOS

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App iPhone bán 4 gói (Personal Pro / Team Growth, tháng / năm) qua In-App Purchase; máy chủ xác minh với Apple và là nguồn sự thật về gói; web hiện đúng gói mua qua App Store.

**Architecture:** App dùng `expo-iap` (StoreKit 2) để mua và gửi giao dịch đã ký (JWS) lên máy chủ. Máy chủ NestJS dùng `@apple/app-store-server-library` xác minh chữ ký, hỏi App Store Server API lấy trạng thái thật, ghi `AppleTransaction` và cập nhật `Subscription` (provider APPLE). Apple gửi App Store Server Notifications V2 về webhook để gia hạn/huỷ/hoàn tiền tự phản ánh. `EntitlementsService` không đổi cách tính quyền lợi.

**Tech Stack:** NestJS 11 + Prisma 7 (Postgres), `@apple/app-store-server-library` 3.1.0, Expo SDK 57 + `expo-iap` 5.8.3 + `expo-crypto`, React web (Vite) với test `node:test` qua `tsx`.

Spec: `docs/superpowers/specs/2026-10-08-apple-iap-design.md`.

## Global Constraints

- Mã sản phẩm Apple trùng mã máy chủ: `pro_monthly`, `pro_yearly`, `team_monthly`, `team_yearly` (từ `src/payments/payment-catalog.ts`).
- Bundle ID `vn.wedo.app`; Apple ID của app `6816878767`; Team ID `LR53W8386S`.
- Ánh xạ trạng thái Apple → nội bộ: 1 Active → ACTIVE/ACTIVE; 4 Grace → GRACE_PERIOD/ACTIVE tới `gracePeriodExpiresDate`; 3 Billing retry → BILLING_RETRY/ACTIVE tới `expiresDate` + 16 ngày; 2 Expired → EXPIRED/EXPIRED; 5 Revoked → REVOKED/CANCELLED ngay.

- Webhook `POST /payments/webhook/apple` không JWT, luôn trả 200 sau khi ghi.
- App: màn Nâng cấp và hàng "Nâng cấp gói" chỉ hiện khi `Platform.OS === 'ios'`; giá lấy từ StoreKit, không ghi cứng; không `finishTransaction` khi máy chủ chưa xác nhận.

```js
// scripts/ops/tao-apple-root-certs.mjs
// Tải 4 chứng chỉ gốc công khai của Apple (DER) và ghi thành base64 vào
// src/payments/apple/apple-root-certs.ts. Chạy lại khi Apple đổi chứng chỉ.
import { writeFileSync } from 'node:fs';

const NGUON = [
  'https://www.apple.com/certificateauthority/AppleRootCA-G2.cer',
  'https://www.apple.com/certificateauthority/AppleRootCA-G3.cer',
  'https://www.apple.com/certificateauthority/AppleIncRootCertificate.cer',
  'https://www.apple.com/certificateauthority/AppleComputerRootCertificate.cer',
];

const base64 = [];
for (const url of NGUON) {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`${url}: HTTP ${res.status}`);
  base64.push(Buffer.from(await res.arrayBuffer()).toString('base64'));
}

const noiDung = `// Sinh bởi scripts/ops/tao-apple-root-certs.mjs — KHÔNG sửa tay.
// Chứng chỉ gốc công khai của Apple (DER, base64) để xác minh JWS của App Store.
export const APPLE_ROOT_CERTS_BASE64: readonly string[] = ${JSON.stringify(base64, null, 2)};
`;
writeFileSync(new URL('../../src/payments/apple/apple-root-certs.ts', import.meta.url), noiDung);
console.log('đã ghi', base64.length, 'chứng chỉ');
```

```ts
// src/payments/apple/apple-mapping.ts
import { AppleSubscriptionStatus, SubscriptionStatus } from '@prisma/client';
import { getPaymentProduct, PaymentProduct } from '../payment-catalog';

/** Apple cho tối đa 16 ngày thu lại tiền (billing retry) trước khi coi là hết hạn. */
export const AN_HAN_THU_LAI_TIEN_MS = 16 * 24 * 60 * 60 * 1000;

export interface KyHanApple {
  appleStatus: AppleSubscriptionStatus;
  subscriptionStatus: SubscriptionStatus;
  /** Mốc hết hạn nội bộ; null khi Apple không cho biết. */
  periodEnd: Date | null;
}

/** Mã sản phẩm trên App Store Connect đặt trùng mã trong catalog, nên tra thẳng. */
export function sanPhamTuProductId(productId: string): PaymentProduct | null {
  return getPaymentProduct(productId) ?? null;
}

/**
 * Trạng thái đăng ký Apple (Status của App Store Server API) → trạng thái nội bộ.
 * 1 Active, 2 Expired, 3 Billing retry, 4 Grace period, 5 Revoked.
 */
export function kyHanTuTrangThaiApple(input: {
  status: number;
  expiresDate?: number;
  gracePeriodExpiresDate?: number;
  now: Date;
}): KyHanApple {
  const hetHan = input.expiresDate ? new Date(input.expiresDate) : null;
  switch (input.status) {
    case 1:
      return { appleStatus: AppleSubscriptionStatus.ACTIVE, subscriptionStatus: SubscriptionStatus.ACTIVE, periodEnd: hetHan };
    case 4:
      return {
        appleStatus: AppleSubscriptionStatus.GRACE_PERIOD,
        subscriptionStatus: SubscriptionStatus.ACTIVE,
        periodEnd: input.gracePeriodExpiresDate ? new Date(input.gracePeriodExpiresDate) : hetHan,
      };
    case 3:
      return {
        appleStatus: AppleSubscriptionStatus.BILLING_RETRY,
        subscriptionStatus: SubscriptionStatus.ACTIVE,
        periodEnd: hetHan ? new Date(hetHan.getTime() + AN_HAN_THU_LAI_TIEN_MS) : null,
      };
    case 5:
      return { appleStatus: AppleSubscriptionStatus.REVOKED, subscriptionStatus: SubscriptionStatus.CANCELLED, periodEnd: input.now };
    case 2:
    default:
      return { appleStatus: AppleSubscriptionStatus.EXPIRED, subscriptionStatus: SubscriptionStatus.EXPIRED, periodEnd: hetHan };
  }
}
```

```ts
// src/payments/apple/apple-config.ts
export interface AppleIapConfig {
  keyId: string;
  issuerId: string;
  privateKey: string;
  environment: 'Sandbox' | 'Production';
}

/**
 * Đọc cấu hình In-App Purchase từ biến môi trường. Thiếu bất kỳ biến nào thì
 * trả null và module Apple tắt (endpoint trả APPLE_IAP_DISABLED), để máy chủ
 * vẫn chạy bình thường khi chưa đặt khoá. Khoá .p8 trên Azure dán một dòng
 * với "\n" chữ, nên đổi lại thành xuống dòng thật.
 */
export function docCauHinhApple(env: NodeJS.ProcessEnv = process.env): AppleIapConfig | null {
  const keyId = env.APPLE_IAP_KEY_ID?.trim();
  const issuerId = env.APPLE_IAP_ISSUER_ID?.trim();
  const privateKey = env.APPLE_IAP_PRIVATE_KEY?.trim().replace(/\\n/g, '\n');
  if (!keyId || !issuerId || !privateKey) return null;
```

```ts
import {
  AppStoreServerAPIClient,
  Environment,
  SignedDataVerifier,
} from '@apple/app-store-server-library';
import { AppleIapConfig } from './apple-config';
import { APPLE_ROOT_CERTS_BASE64 } from './apple-root-certs';

const BUNDLE_ID = 'vn.wedo.app';
const APP_APPLE_ID = 6816878767;

export interface GiaoDichDaXacMinh {
  originalTransactionId: string;
  transactionId: string;
  productId: string;
  environment: string;
  appAccountToken?: string;
  purchaseDate: number;
  expiresDate?: number;
  revocationDate?: number;
}

export interface TrangThaiDangKy {
  status: number;
  giaoDich: GiaoDichDaXacMinh;
  gracePeriodExpiresDate?: number;
  autoRenewStatus?: number;
}

export interface ThongBaoDaXacMinh {
  notificationType: string;
  subtype?: string;
  environment?: string;
  status?: number;
  giaoDich?: GiaoDichDaXacMinh;
  gracePeriodExpiresDate?: number;
  autoRenewStatus?: number;
}

/** Bọc thư viện Apple sau một interface để service test được bằng bản giả. */
export interface BoXacMinhApple {
  xacMinhGiaoDich(jws: string): Promise<GiaoDichDaXacMinh>;
  layTrangThaiDangKy(originalTransactionId: string): Promise<TrangThaiDangKy | null>;
  xacMinhThongBao(signedPayload: string): Promise<ThongBaoDaXacMinh>;
}

export const BO_XAC_MINH_APPLE = Symbol('BO_XAC_MINH_APPLE');

function moiTruong(config: AppleIapConfig): Environment {
  return config.environment === 'Sandbox' ? Environment.SANDBOX : Environment.PRODUCTION;
}

function rutGiaoDich(p: {
  originalTransactionId?: string;
  transactionId?: string;
  productId?: string;
  environment?: string;
  appAccountToken?: string;
  purchaseDate?: number;
  expiresDate?: number;
  revocationDate?: number;
}): GiaoDichDaXacMinh {
  if (!p.originalTransactionId || !p.transactionId || !p.productId || !p.purchaseDate) {
    throw new Error('Giao dịch Apple thiếu trường bắt buộc.');
  }
  return {
    originalTransactionId: p.originalTransactionId,
    transactionId: p.transactionId,
    productId: p.productId,
    environment: String(p.environment ?? ''),
    appAccountToken: p.appAccountToken,
    purchaseDate: p.purchaseDate,
    expiresDate: p.expiresDate,
    revocationDate: p.revocationDate,
  };
}

export function taoBoXacMinhApple(config: AppleIapConfig): BoXacMinhApple {
  const certs = APPLE_ROOT_CERTS_BASE64.map((b) => Buffer.from(b, 'base64'));
  const verifier = new SignedDataVerifier(certs, true, moiTruong(config), BUNDLE_ID, APP_APPLE_ID);
  const client = new AppStoreServerAPIClient(
    config.privateKey,
    config.keyId,
    config.issuerId,
    BUNDLE_ID,
    moiTruong(config),
  );

  return {
    async xacMinhGiaoDich(jws) {
      return rutGiaoDich(await verifier.verifyAndDecodeTransaction(jws));
    },

    async layTrangThaiDangKy(originalTransactionId) {
      const res = await client.getAllSubscriptionStatuses(originalTransactionId);
      for (const nhom of res.data ?? []) {
        for (const item of nhom.lastTransactions ?? []) {
          if (item.originalTransactionId !== originalTransactionId || !item.signedTransactionInfo) continue;
          const giaoDich = rutGiaoDich(await verifier.verifyAndDecodeTransaction(item.signedTransactionInfo));
          const renewal = item.signedRenewalInfo
            ? await verifier.verifyAndDecodeRenewalInfo(item.signedRenewalInfo)
            : undefined;
          return {
            status: Number(item.status ?? 2),
            giaoDich,
            gracePeriodExpiresDate: renewal?.gracePeriodExpiresDate,
            autoRenewStatus: renewal?.autoRenewStatus === undefined ? undefined : Number(renewal.autoRenewStatus),
          };
        }
      }
      return null;
    },

    async xacMinhThongBao(signedPayload) {
      const payload = await verifier.verifyAndDecodeNotification(signedPayload);
      const data = payload.data;
      const giaoDich = data?.signedTransactionInfo
        ? rutGiaoDich(await verifier.verifyAndDecodeTransaction(data.signedTransactionInfo))
        : undefined;
      const renewal = data?.signedRenewalInfo
        ? await verifier.verifyAndDecodeRenewalInfo(data.signedRenewalInfo)
        : undefined;
      return {
        notificationType: String(payload.notificationType ?? ''),
        subtype: payload.subtype ? String(payload.subtype) : undefined,
        environment: data?.environment ? String(data.environment) : undefined,
        status: data?.status === undefined ? undefined : Number(data.status),
        giaoDich,
        gracePeriodExpiresDate: renewal?.gracePeriodExpiresDate,
        autoRenewStatus: renewal?.autoRenewStatus === undefined ? undefined : Number(renewal.autoRenewStatus),
      };
    },
  };
}
```

```ts
// src/payments/apple/apple-iap.service.ts
import {
  BadRequestException,
  ConflictException,
  ForbiddenException,
  Inject,
  Injectable,
  Optional,
  ServiceUnavailableException,
} from '@nestjs/common';
import { AppleSubscriptionStatus, Prisma, SubscriptionProvider, SubscriptionStatus } from '@prisma/client';
import { OperationalLogger } from '../../common/operational-logger';
import { PrismaService } from '../../prisma/prisma.service';
import { PaymentProduct } from '../payment-catalog';
import { kyHanTuTrangThaiApple, sanPhamTuProductId } from './apple-mapping';
import { BO_XAC_MINH_APPLE, BoXacMinhApple, GiaoDichDaXacMinh, ThongBaoDaXacMinh } from './apple-verifier';
import { GhiNhanGiaoDichDto } from './dto/ghi-nhan-giao-dich.dto';

export interface KetQuaGhiNhan {
  transactionId: string;
  subscription: {
    plan: string;
    status: SubscriptionStatus;
    billingCycle: string;
    currentPeriodEnd: Date;
    provider: 'APPLE';
  } | null;
}

/** Thông báo V2 làm đổi gói; loại khác chỉ ghi log. */
const LOAI_THONG_BAO_XU_LY = new Set([
  'SUBSCRIBED', 'DID_RENEW', 'DID_CHANGE_RENEWAL_STATUS', 'DID_CHANGE_RENEWAL_PREF',
  'DID_FAIL_TO_RENEW', 'GRACE_PERIOD_EXPIRED', 'EXPIRED', 'REFUND', 'REVOKE',
]);

@Injectable()
export class AppleIapService {
  private readonly logger = new OperationalLogger(AppleIapService.name);

  constructor(
    private readonly prisma: PrismaService,
    @Optional() @Inject(BO_XAC_MINH_APPLE) private readonly boXacMinh: BoXacMinhApple | null,
    private readonly bayGio: () => Date = () => new Date(),
  ) {}

  daBat() {
    return this.boXacMinh !== null;
  }

  async ghiNhanGiaoDich(userId: string, dto: GhiNhanGiaoDichDto): Promise<KetQuaGhiNhan> {
    const bo = this.batBuocBat();
    let giaoDich: GiaoDichDaXacMinh;
    try {
      giaoDich = await bo.xacMinhGiaoDich(dto.jws);
    } catch (error) {
      this.logger.warn('apple.transaction.invalid', { userId, reason: String(error) });
      throw new BadRequestException({ code: 'APPLE_TRANSACTION_INVALID', message: 'Giao dịch App Store không hợp lệ.' });
    }
    const sanPham = sanPhamTuProductId(giaoDich.productId);
    if (!sanPham) {
      throw new BadRequestException({ code: 'APPLE_TRANSACTION_INVALID', message: `Sản phẩm ${giaoDich.productId} không có trong catalog.` });
    }
    if (sanPham.scope === 'WORKSPACE' && !dto.workspaceId) {
      throw new BadRequestException({ code: 'APPLE_TRANSACTION_INVALID', message: 'Gói Team cần workspaceId.' });
    }
    const workspaceId = sanPham.scope === 'WORKSPACE' ? dto.workspaceId! : null;
    if (workspaceId) await this.kiemChuWorkspace(userId, workspaceId);

    // Trạng thái thật lấy từ Apple, không tin giao dịch app gửi (có thể cũ).
    const trangThai = await bo.layTrangThaiDangKy(giaoDich.originalTransactionId);
    const now = this.bayGio();
    const kyHan = kyHanTuTrangThaiApple({
      status: trangThai?.status ?? (giaoDich.revocationDate ? 5 : 1),
      expiresDate: trangThai?.giaoDich.expiresDate ?? giaoDich.expiresDate,
      gracePeriodExpiresDate: trangThai?.gracePeriodExpiresDate,
      now,
    });
    const giaoDichMoiNhat = trangThai?.giaoDich ?? giaoDich;

    return this.prisma.$transaction(async (tx) => {
      const cu = await tx.appleTransaction.findUnique({ where: { originalTransactionId: giaoDich.originalTransactionId } });
      if (cu?.userId && cu.userId !== userId) {
        throw new ConflictException({ code: 'TRANSACTION_OWNED_BY_OTHER_USER', message: 'Đăng ký App Store này thuộc một tài khoản WeDo khác.' });
      }
      if (cu && cu.transactionId === giaoDichMoiNhat.transactionId && cu.subscriptionId && cu.userId === userId) {
        const sub = await tx.subscription.findFirst({ where: { id: cu.subscriptionId } });
        return { transactionId: cu.transactionId, subscription: sub ? this.goiRa(sub) : null };
      }
      if (workspaceId) {
        const khac = await tx.appleTransaction.findFirst({ where: { workspaceId, NOT: { originalTransactionId: giaoDich.originalTransactionId } } });
        if (khac && khac.status !== AppleSubscriptionStatus.EXPIRED && khac.status !== AppleSubscriptionStatus.REVOKED) {
          throw new ConflictException({ code: 'SUBSCRIPTION_CONFLICT', message: 'Workspace này đã có một đăng ký App Store khác.' });
        }
      }
      await this.chanTrungGoiPayos(tx, sanPham, userId, workspaceId, now);

      const sub = await this.capNhatSubscription(tx, sanPham, userId, workspaceId, kyHan, now);
      await tx.appleTransaction.upsert({
        where: { originalTransactionId: giaoDich.originalTransactionId },
        create: {
          originalTransactionId: giaoDich.originalTransactionId,
          transactionId: giaoDichMoiNhat.transactionId,
          productId: giaoDichMoiNhat.productId,
          environment: giaoDichMoiNhat.environment,
          appAccountToken: giaoDich.appAccountToken ?? null,
          status: kyHan.appleStatus,
          purchasedAt: new Date(giaoDichMoiNhat.purchaseDate),
          expiresAt: giaoDichMoiNhat.expiresDate ? new Date(giaoDichMoiNhat.expiresDate) : null,
          autoRenew: trangThai?.autoRenewStatus === undefined ? true : trangThai.autoRenewStatus === 1,
          userId,
          workspaceId,
          subscriptionId: sub.id,
        },
        update: {
          transactionId: giaoDichMoiNhat.transactionId,
          productId: giaoDichMoiNhat.productId,
          status: kyHan.appleStatus,
          expiresAt: giaoDichMoiNhat.expiresDate ? new Date(giaoDichMoiNhat.expiresDate) : null,
          userId,
          workspaceId,
          subscriptionId: sub.id,
        },
      });
      this.logger.info('apple.transaction.recorded', { userId, workspaceId, productId: giaoDichMoiNhat.productId, status: kyHan.appleStatus });
      return { transactionId: giaoDichMoiNhat.transactionId, subscription: this.goiRa(sub) };
    });
  }

  async xuLyThongBao(signedPayload: string): Promise<void> {
    // Viết ở Task A6.
    void signedPayload;
  }

  private batBuocBat(): BoXacMinhApple {
    if (!this.boXacMinh) {
      throw new ServiceUnavailableException({ code: 'APPLE_IAP_DISABLED', message: 'Máy chủ chưa bật thanh toán App Store.' });
    }
    return this.boXacMinh;
  }

  private async kiemChuWorkspace(userId: string, workspaceId: string) {
    const ws = await this.prisma.workspace.findUnique({ where: { id: workspaceId }, select: { id: true, ownerId: true } });
    if (!ws || ws.ownerId !== userId) {
      throw new ForbiddenException({ code: 'WORKSPACE_OWNER_REQUIRED', message: 'Chỉ chủ workspace mới mua được gói Team cho workspace đó.' });
    }
  }

  /** Người/workspace đang có gói payOS còn hạn thì không cho mua chồng trên iPhone. */
  private async chanTrungGoiPayos(
    tx: Prisma.TransactionClient,
    sanPham: PaymentProduct,
    userId: string,
    workspaceId: string | null,
    now: Date,
  ) {
    const where = sanPham.scope === 'USER' ? { userId } : { workspaceId: workspaceId! };
    const hienCo = await tx.subscription.findFirst({ where });
    if (
      hienCo &&
      hienCo.provider === SubscriptionProvider.PAYOS &&
      hienCo.status === SubscriptionStatus.ACTIVE &&
      hienCo.currentPeriodEnd > now
    ) {
      throw new ConflictException({
        code: 'SUBSCRIPTION_CONFLICT',
        message: 'Gói hiện tại mua trên web còn hạn. Mua trên iPhone sau khi gói đó hết hạn.',
        currentPeriodEnd: hienCo.currentPeriodEnd,
      });
    }
  }

  private async capNhatSubscription(
    tx: Prisma.TransactionClient,
    sanPham: PaymentProduct,
    userId: string,
    workspaceId: string | null,
    kyHan: ReturnType<typeof kyHanTuTrangThaiApple>,
    now: Date,
  ) {
    const scopeKey = sanPham.scope === 'USER' ? `user:${userId}` : `workspace:${workspaceId}`;
```

```ts
import { QUYEN_LOI } from './quyen-loi';

export type MaGoi = 'pro_monthly' | 'pro_yearly' | 'team_monthly' | 'team_yearly';
export const MA_GOI: readonly MaGoi[] = ['pro_monthly', 'pro_yearly', 'team_monthly', 'team_yearly'];

export interface TheGoi {
  ten: 'Personal Pro' | 'Team Growth';
  plan: 'PERSONAL_PRO' | 'TEAM_GROWTH';
  thang: { sku: MaGoi; gia: string } | null;
  nam: { sku: MaGoi; gia: string } | null;
  quyenLoi: readonly string[];
}

/** Ghép sản phẩm StoreKit (giá đã định dạng theo cửa hàng) thành hai thẻ. Thiếu sản phẩm thì ô đó null. */
export function ghepTheGoi(sanPham: Array<{ id: string; displayPrice: string }>): TheGoi[] {
  const gia = (sku: MaGoi) => {
    const sp = sanPham.find((p) => p.id === sku);
    return sp ? { sku, gia: sp.displayPrice } : null;
  };
  return [
    { ten: 'Personal Pro', plan: 'PERSONAL_PRO', thang: gia('pro_monthly'), nam: gia('pro_yearly'), quyenLoi: QUYEN_LOI.PERSONAL_PRO },
    { ten: 'Team Growth', plan: 'TEAM_GROWTH', thang: gia('team_monthly'), nam: gia('team_yearly'), quyenLoi: QUYEN_LOI.TEAM_GROWTH },
  ];
}

export function workspaceMinhLamChu(
  workspaces: Array<{ id: string; name: string; ownerId: string }>,
  userId: string,
): Array<{ id: string; name: string }> {
  return workspaces.filter((w) => w.ownerId === userId).map((w) => ({ id: w.id, name: w.name }));
}

function ngayVN(iso: string) {
  const d = new Date(iso);
  return Number.isNaN(d.getTime()) ? '' : d.toLocaleDateString('vi-VN', { day: '2-digit', month: '2-digit', year: 'numeric', timeZone: 'Asia/Ho_Chi_Minh' });
}

/** Dịch lỗi mua thành một câu; rỗng nghĩa là không cần báo (người dùng tự huỷ). */
export function loiNhanMua(loi: unknown): string {
  const l = (loi ?? {}) as { code?: string; currentPeriodEnd?: string; message?: string };
  switch (l.code) {
    case 'user-cancelled':
      return '';
    case 'SUBSCRIPTION_CONFLICT':
      return l.currentPeriodEnd
        ? `Gói hiện tại mua trên web còn đến ${ngayVN(l.currentPeriodEnd)}. Mua trên iPhone sau ngày đó nhé.`
        : 'Bạn đang có gói khác còn hạn.';
    case 'TRANSACTION_OWNED_BY_OTHER_USER':
      return 'Đăng ký App Store này đang gắn với một tài khoản WeDo khác.';
    case 'WORKSPACE_OWNER_REQUIRED':
      return 'Chỉ chủ workspace mới mua được gói Team cho workspace đó.';
    case 'APPLE_IAP_DISABLED':
      return 'Thanh toán qua App Store tạm chưa mở. Bạn thử lại sau nhé.';
    default:
      return 'Chưa mua được. Bạn thử lại sau nhé.';
  }
}
```

Kiểm `apiRequest` ném lỗi có `code` từ body máy chủ (xem `src/lib/api/client.ts`, class lỗi hiện có); nếu lỗi là `ApiError` với `body.code`, sửa `loiNhanMua` đọc `l.body?.code` thay vì `l.code` cho khớp.

```tsx
import React, { useCallback, useEffect, useMemo, useState } from 'react';
import { ActivityIndicator, Platform, Pressable, ScrollView, StyleSheet, Text, View } from 'react-native';
import { useQueryClient } from '@tanstack/react-query';
import { deepLinkToSubscriptions, useIAP, type Purchase } from 'expo-iap';
import { guiGiaoDichApple, layAppAccountToken } from '../../lib/api/apple-iap';
import { useAuth } from '../../lib/auth/auth-context';
import { useWorkspace } from '../../lib/workspace/workspace-context';
import { ghepTheGoi, loiNhanMua, MA_GOI, workspaceMinhLamChu, type MaGoi, type TheGoi } from '../../lib/payments/mua-goi';
import { colors } from '../../theme/colors';

/*
  Màn Nâng cấp (chỉ iOS). Mọi giá lấy từ StoreKit. Giao dịch về thì gửi máy
  chủ xác minh, máy chủ xác nhận rồi mới finishTransaction: máy chủ hỏng thì
  giữ giao dịch, StoreKit đưa lại ở lần mở sau và ta gửi lại.
*/
export default function ManNangCap() {
  const { user } = useAuth();
  const { workspaces } = useWorkspace();
  const queryClient = useQueryClient();
  const [dangMua, setDangMua] = useState<MaGoi | null>(null);
  const [dangKichHoat, setDangKichHoat] = useState(false);
  const [loi, setLoi] = useState('');
  const [workspaceChon, setWorkspaceChon] = useState<string | null>(null);

  const cuaToi = useMemo(() => workspaceMinhLamChu(workspaces, user?.id ?? ''), [workspaces, user?.id]);
  const workspaceTeam = workspaceChon ?? cuaToi[0]?.id ?? null;

  const xuLyGiaoDich = useCallback(
    async (purchase: Purchase) => {
      const jws = purchase.purchaseToken;
      if (!jws) return;
      setDangKichHoat(true);
      try {
        const laTeam = purchase.productId.startsWith('team_');
        await guiGiaoDichApple({ jws, workspaceId: laTeam ? (workspaceTeam ?? undefined) : undefined });
        await finishTransaction({ purchase });
        await queryClient.invalidateQueries({ queryKey: ['entitlements'] });
        setLoi('');
      } catch (e) {
        // Không finish: StoreKit sẽ đưa lại giao dịch, ta gửi lại lần mở sau.
        setLoi(loiNhanMua(e) || 'Đã thanh toán, đang kích hoạt gói… Mở lại app nếu chưa thấy gói.');
      } finally {
        setDangKichHoat(false);
        setDangMua(null);
      }
    },
    [workspaceTeam, queryClient],
  );

  const { connected, subscriptions, fetchProducts, requestPurchase, finishTransaction, getAvailablePurchases } = useIAP({
    onPurchaseSuccess: (p) => void xuLyGiaoDich(p),
    onPurchaseError: (e) => {
      setDangMua(null);
      setLoi(loiNhanMua(e));
    },
  });

  useEffect(() => {
```

```ts
import type { GoiHienTai } from '../api/entitlements';

}
```
